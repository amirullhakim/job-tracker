# Job Application Tracker

A full-stack web application for organising and tracking job applications.

## Features

- User registration and login
- JWT authentication
- Private applications for each user
- Add, view, edit and delete job applications
- Search, filter and sorting
- Application status tracking
- Dashboard statistics
- Recent applications
- Profile settings
- Light, Dark and System themes
- Responsive desktop and mobile interface

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM

### Database
- PostgreSQL
